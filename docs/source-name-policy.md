# 中文名称的自动选择

名称核验在 GitHub 执行，不移到电视端。

1. 通过原名、年份、类型、季数核实豆瓣作品身份，保留该条目的原始名称。
2. 使用 YDC Research 查询这部影视作品在中国使用的名称；回答为空、服务不可用或额度不足时尝试 Tavily 的答案接口。提供演员和作品背景，区分同名书籍。Gemini 不参与查名。
3. AI 回答及既有线索只是查询词，不是显示名称的批准。按上限查询片库，再核对作品编号、年份、类型、季数及必要的主创资料。
4. 通过身份核验、且确实提供播放条目的片库记录可以参与名称投票。名称可用与线路当前可播分开记录：链接过期、解析失败、部分线路失效不会撤销已经确认的片名。同一片库多条线路只计一个片库，按支持该名称的片库数量选择片库实际名称。
5. 明确由用户确认的片库名称，按官方作品、豆瓣编号、年份、季数绑定后也可保留；报告注明用户确认，不冒充本轮接口核验。没有片库名称证据时，显示豆瓣原始名称，即使仍为英文。不改用未经片库验证的 AI 或 Plex 名称。网络超时、403、451 保留诊断和后续重试机会，不视为未收录。

AI 请求有账户预算，答案按作品身份缓存；片库查询有并发、数量、时间和分页上限。接口或参数错误不会通过反复切换同一服务的账户来重试。

名称核验不更新线路可播状态，也不代表清单或分片已访问成功、电视播放器实际出画面。线路可用性由独立流程检查。

每轮证据可查看 [查名记录](../logs/mainland-name-sync.json)。
